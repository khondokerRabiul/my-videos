# SCENE TYPES (reconstruction-3d)

| # | type   | visual engine render                                   | tint        |
|---|--------|--------------------------------------------------------|-------------|
| 1 | hook   | starfield tunnel w/ motion streaks                     | teal cyan   |
| 2 | reveal | rotating wireframe globe + perspective floor grid      | deep blue   |
| 3 | proof  | wave grid + floating monolith cubes                    | amber       |
| 4+ | extra | mixes of the above with faster cuts                    | alternating |
| N | outro  | hyperspace streaks + burning core + title drop         | warm white  |

- Scene boundaries get a flash + SFX (whoosh/boom/sparkle cycle).
- Titles auto-scale; one title per scene; HUD shows `3D RECON` + `REC <sec>`.
- All scene starts are driven by `output/voice/timings.json` — writing new scene
  text in config.json automatically extends the video.
