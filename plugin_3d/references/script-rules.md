# SCRIPT RULES (OpenCode edition)

When OpenCode writes the scene script into `config.json`:

1. **4–6 scenes** for a 30–60s full video; 1 line per scene (~2–9s spoken).
2. Sentence rhythm: "Deep beneath... quietly built." — short, punched, ellipses OK.
3. Scene 1 = HOOK (3–7 words), Scene 2 = REVEAL (the idea, stated as fact),
   Scene 3 = PROOF (specific, visual words: grid, cube, globe, cut), final = OUTRO (title drop).
4. No lists, no jargon, no emoji in voice text. Friendly to TTS: avoid abbreviations.
5. Keep each line under ~110 characters so gTTS/edge-tts stays crisp.
6. Every scene text gets its own 2.5D scene in the renderer — write VISUAL words
   (machine, built, attention, three dimensions) that map to the look.
